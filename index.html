ℹ️ About This Project

AI Career Suggestion System


This project uses a JavaScript-based content matching engine to recommend suitable careers based on student interests, skills, subjects and education.


Technologies


HTML5
CSS3
JavaScript
TF-IDF Inspired Matching
Cosine Similarity


Project Type: Browser-based career recommendation prototype.

Dataset: This standalone version uses a built-in career knowledge base, not the previous external Kaggle/Hugging Face dataset.

Limitation: Suggestions are guidance only, not scientifically validated aptitude results or job guarantees.
